# 需求文档 — 番茄钟桌面应用

## 概述

一款极简风格的 Windows 桌面番茄钟软件。系统托盘驻留，支持任务管理，帮助用户在专注工作和规律休息之间保持平衡。

## 功能需求

### P0 — 核心必须

| ID | 功能 | 描述 |
|----|------|------|
| F1 | 工作计时 | 倒计时显示，默认 25 分钟，到时自动通知 |
| F2 | 短休息 | 默认 5 分钟，工作阶段结束后自动进入 |
| F3 | 长休息 | 默认 15 分钟，每完成 4 个番茄后触发 |
| F4 | 开始/暂停/跳过 | 基础计时控制 |
| F5 | 系统托盘驻留 | 关闭窗口时最小化到托盘，后台运行 |
| F6 | 视觉通知 | 计时结束时系统通知 + 窗口闪烁 |

### P1 — 重要

| ID | 功能 | 描述 |
|----|------|------|
| F7 | 任务清单 | 增/删/改/查 待办任务 |
| F8 | 番茄绑定任务 | 开始番茄时可选择绑定到某个任务 |
| F9 | 无任务番茄 | 可不绑定任务直接开始番茄 |
| F10 | 自定义时长 | 工作/短休/长休时长可调整 |
| F11 | 每次完成番茄数 | 触发长休息的番茄数可配置 |

### P2 — 增强

| ID | 功能 | 描述 |
|----|------|------|
| F12 | 今日统计 | 今日完成番茄数、总专注时间 |
| F13 | 自动开始下一阶段 | 可配置是否自动开始休息/工作 |
| F14 | 窗口置顶 | 可配置是否始终置顶 |
| F15 | 暗色模式 | 默认暗色主题，护眼 |

## 非功能需求

| ID | 描述 |
|----|------|
| NF1 | 计时精度：倒计时误差 < 1 秒 |
| NF2 | 资源占用：托盘后台运行时内存 < 100MB |
| NF3 | 启动速度：冷启动 < 3 秒 |
| NF4 | 数据持久化：本地存储，离线可用 |
