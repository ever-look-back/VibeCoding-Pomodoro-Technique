# 设计规范 — 番茄钟桌面应用

## 设计原则

1. **极简至上**：每个屏幕只展示当前最必要的信息，减少认知负荷
2. **暗色优先**：默认暗色主题，长时间使用不刺眼
3. **一目了然**：倒计时数字为视觉重心，字号最大
4. **操作无阻**：常用操作（开始/暂停/跳过）不超过 1 次点击

## 色彩系统

```
背景主色    #0f0f0f  (深黑，主背景)
背景次色    #1a1a1a  (卡片/面板背景)
边框色      #2a2a2a  (分割线)
文字主色    #f0f0f0  (主文字，高对比)
文字次色    #888888  (辅助信息)
强调色      #e53935  (番茄红，工作阶段标识)
成功色      #43a047  (绿色，休息阶段标识)
警告色      #ff9800  (橙色，即将结束闪烁)
```

## 字体

| 用途 | 字体 | 说明 |
|------|------|------|
| 倒计时数字 | System UI monospace, tabular-nums | 等宽数字，防止宽度跳动 |
| 标题/正文 | System UI sans-serif | 系统原生无衬线字体 |

## 窗口规格

| 属性 | 值 |
|------|-----|
| 默认尺寸 | 360 × 500 px |
| 最小尺寸 | 320 × 400 px |
| 圆角 | 12px（Windows 11 风格） |
| 默认置顶 | 否（可在设置中开启） |

## 布局结构

```
┌────────────────────────────┐
│        阶段标识 & 番茄计数    │  ← 小字，图标
│                            │
│                            │
│         25:00              │  ← 大号倒计时，视觉重心
│                            │
│                            │
│    [开始] [跳过]            │  ← 控制按钮
│                            │
├────────────────────────────┤
│  当前任务：复习数学          │  ← 已绑定任务显示
│────────────────────────────│
│  □ 任务1       🍅×2       │
│  □ 任务2       🍅×1       │  ← 任务列表
│  □ 任务3       🍅×0       │
│────────────────────────────│
│  + 添加任务                │
├────────────────────────────┤
│  ⚙ 设置  │  📊 统计       │  ← 底部导航
└────────────────────────────┘
```

## 交互规范

- 计时器区域点击可切换 开始/暂停
- 任务项左滑或右键可删除
- 数字用 CSS transition 实现平滑变化（非机械跳变）
- 阶段切换时有背景色渐变过渡（300ms ease）
- 最后 5 秒倒计时数字变为警告色并脉冲闪烁
